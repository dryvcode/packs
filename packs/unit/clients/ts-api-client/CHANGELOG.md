# Changelog

## 0.1.3

- Allow callers to configure fetch credential mode for cookie-authenticated APIs.

## 0.1.2

- Export generated operations, models, and enums through package subpaths.

## 0.1.1

- Use the configured `package_name` for the generated package manifest.

## 0.1.0

- First release: models, enums, one typed fetch call per HTTP operation, `configureApi`.

- Generate and export `requestBlob` for authenticated binary downloads.
